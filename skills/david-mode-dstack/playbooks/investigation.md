# Investigation

Use for a read-only question or recommendation.

1. State the exact question and evidence needed to answer it.
2. Read repository guidance and trace the relevant source with `$how-dstack` or `$why-dstack`.
3. Use context-only Studio inspection only for missing authored information. Never control a playtest.
4. Separate observed behavior, intended behavior, inference, and unresolved gaps.
5. Return the answer with exact paths and the smallest useful next action. Do not edit files.
